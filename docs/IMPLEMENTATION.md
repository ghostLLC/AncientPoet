## 设计与实现取舍

采用 PostgreSQL 持久任务，减少单独 Redis 队列的运行依赖，保留可恢复和可核对的状态；当前规模不新增消息中间件。并发服务实例可使用数据库领取机制，但本次没有把它当作多实例容量认证。

优先恢复文字书信的可信反馈与连续性，再改善阅读和导航。地图明确作为示意；历史资料的核校范围明确到具体诗词，避免用视觉完整度掩盖内容不足。

本次合成模型便于稳定重现超时/失败/恢复，不足以判断真实模型文学质量。后续真实供应商和真机验收应沿用 [验证记录](VERIFICATION.md) 的边界。
